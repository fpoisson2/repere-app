# Screenshots

Drop real screenshots here with these exact filenames and the presentation
page (`frontend/about.html`) picks them up automatically, replacing the
placeholder frames:

- `android-today.png` — daily check-in screen
- `android-trends.png` — trends and statistics screen
- `android-bac.png` — BAC estimate screen
- `wear-complication.png` — Wear OS complication

Recommended aspect ratio: ~9:18.5 for phone shots, 1:1 for the watch shot.
